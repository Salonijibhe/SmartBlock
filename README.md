# Official Website

A modern and responsive website developed for **Creator Research**, showcasing the company's services across **six key service domains** with a clean and user-friendly interface.

🌐 **Official Website:** https://www.creatorresearch.com/

## 🚀 Features

* Professional and responsive website design
* Six service domains showcased clearly
* Modern and user-friendly interface
* Responsive across desktop, tablet, and mobile devices
* Structured service and company information
* Fast and scalable web architecture
* Deployed on Vercel

## 🛠️ Tech Stack

* **Next.js** – React framework for building the web application
* **Tailwind CSS** – Responsive and modern UI styling
* **PostgreSQL** – Database management
* **Vercel** – Deployment and hosting
* **Git & GitHub** – Version control and project management
